Privacy Policy

Last updated: November 2026

ClipFarm is a personal tool operated by its owner for their own accounts only. It has no other users and does not offer accounts, sign-ups or services to the public.

What data ClipFarm uses

  • Videos the owner provides: links to the owner's own (or licensed) streams and videos, the clips cut from them, and their transcripts.
  • Platform access tokens: when the owner connects their YouTube, TikTok or Instagram account, ClipFarm stores the access/refresh tokens those platforms issue, so it can publish clips the owner approved.
  • Basic account information returned by the platforms (such as the account id and username), used only to confirm which account is connected.

How the data is used

  • Tokens are used only to upload and publish videos the owner has approved, to the owner's own account, and to read back the link to the published video.
  • ClipFarm does not read, collect or analyse other users' data, comments, followers or messages.
  • Data is not sold, shared with third parties, used for advertising, or used to train models.

YouTube API Services

ClipFarm uses the YouTube API Services to upload videos to the owner's channel. By connecting a YouTube account, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. ClipFarm's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at Google security settings.

TikTok and Instagram

ClipFarm uses the TikTok Content Posting API and the Instagram API only to publish the owner's approved clips to the owner's own accounts. Access can be revoked at any time in each app's settings (TikTok: Settings → Security → Manage app permissions; Instagram: Settings → Apps and websites).

Storage and retention

Data is stored on a private server controlled by the owner and, for publishing, in a private-by-default storage bucket. Clips are deleted automatically after a short retention period (about 10 days); tokens are deleted when an account is disconnected.
